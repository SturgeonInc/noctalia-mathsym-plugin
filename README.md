# noctalia-unicode-picker

Source repo for the `unicode-picker` Noctalia plugin (see `unicode-picker/README.md`).

- `make data` regenerate `unicode-picker/data.tsv` from `tools/sources/`
- `make fetch-sources` refresh the vendored sources
- `make check` sanity-check the data
- `make install` / `make uninstall` copy the plugin to / remove it from `~/.local/share/noctalia/plugins/`
