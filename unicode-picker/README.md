# Unicode Picker

Noctalia launcher provider for finding unicode characters by **LaTeX name** or **Lean 4 VS Code input-method name**.

Type `/uni` in the launcher, then:

| Query | Finds |
|---|---|
| `\alpha`, `alpha` | α |
| `le`, `leq` | ≤ (exact matches rank first, then prefix, then substring) |
| `mathbb{R}`, `mathbb R`, `BbbR` | ℝ |
| `Rightarrow` vs `rightarrow` | ⇒ vs → (case-sensitive exact matches win) |
| `integral` | description match |

Enter copies the character to the clipboard.

## Settings
- `notify_on_copy` (bool, default true): show a notification after copying.
- `paste_mode` (default off): after copying, also paste into the focused window with `wtype`. `type` types the character itself (works in terminals and GUI apps); `ctrl_v`, `ctrl_shift_v` and `shift_insert` send that shortcut instead. Noctalia's own `auto_paste` setting does not apply to plugin providers.
- `paste_delay_ms` (default 150): wait after the launcher closes so focus returns to the previous window before pasting.

## Data and licenses
`data.tsv` is generated by `tools/build_data.py` from:
- `unicode-math-table.tex` from the LaTeX `unicode-math` package (LPPL), plus `\mathbb{X}`-style aliases derived from its `\BbbX`, `\mbfX`, ... names.
- `abbreviations.json` from [leanprover/vscode-lean4](https://github.com/leanprover/vscode-lean4) (Apache-2.0).

## Performance
Noctalia gives each script callback 25 ms of CPU time, too little to parse the data in Luau. The launcher script therefore runs `search.py` (Python 3, about 35 ms per query) through `noctalia.runAsync`, which is not metered, and relays the JSON rows.
